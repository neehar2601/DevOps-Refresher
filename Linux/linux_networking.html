Process Management

Monitoring Processes

  • ps Displays a snapshot of current running processes. Use ps aux for a detailed view of all users' processes.
  • top Real-time, dynamic view of running processes. Shows CPU, Memory usage, and system load.
  • htop An enhanced, interactive version of top (usually requires installation). Allows scrolling and color-coded meters.

Terminating Processes

Processes are terminated by sending them signals using the kill command.

  • kill PID Sends a graceful termination signal (SIGTERM) to the specific Process ID.
  • kill -9 PID Sends a forceful kill signal (SIGKILL). Use only when a process is unresponsive.
  • killall name Kills all processes matching the specified name.

Networking Essentials

ip

Replaces the deprecated ifconfig command.

ip a

Shows all IP addresses associated with all network interfaces.

ping

Tests connectivity to another host.

ping google.com

Sends ICMP ECHO_REQUEST packets. Use -c 4 to limit count.

ss

Utility to investigate sockets (modern replacement for netstat).

ss -tuln

Shows all listening TCP/UDP ports numerically.

curl

Transfers data from or to a server.

curl -I https://api.io

Fetches only the HTTP headers. Extremely versatile for API testing.

SSH (Secure Shell)

Used for securely connecting to remote servers.

ssh user@192.168.1.10

By default uses port 22. Can use identity files via -i key.pem.
